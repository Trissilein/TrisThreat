# TrisThreat

TrisThreat is a small World of Warcraft addon that puts a capsule on every enemy nameplate and shows how much threat you hold on that enemy.

## Version

Current stable version: **0.1.0**.

Retail compatibility: **12.1.5** (interface **120105**). WoW Forever compatibility (beta): interface **16001** (`TrisThreat_Camelot.toc`). One package serves both.

## What it does

- A threat element on each enemy nameplate that fights you, with the threat value (for example `70%`).
- The color grades continuously with your threat, one step per percent: green at 0 %, yellow at 50 %, red at 100 %. As a tank holding the enemy it follows your lead over the next player instead: full and green with a big lead, shrinking and turning red as they close in.
- Role detection is automatic (stance, form or aura of a tank, then the assigned group role, then your specialization role; on WoW Forever a Warrior or Paladin is a tank when a shield is equipped and no other tank is in the group, whatever aura or stance is active; the tooltip and the settings show which rule decided) and can be overridden in the settings.
- When another tank or your pet holds the enemy, the capsule turns blue instead of red (tank only).
- Four display modes in Blizzard's own nameplate art: a second level badge (left, right, top or bottom of the health bar), a segment inside the bar's end, a thin strip above or below the bar whose fill is your threat, or a floating capsule you move up to 100 pixels in every direction. Integrated modes can move the name, raid icon and crowd-control icons aside to make room.
- Color the number, the background, the nameplate bar, or any combination.
- The settings window shows a live copy of the Blizzard nameplate; while it is open, your target gets a test element without combat.
- Settings from `/tristhreat` (or `/tt`), the addon compartment, a Titan Panel / LibDataBroker button or the minimap icon. Right-click the minimap icon to hide it; **Show minimap icon** in the settings brings it back.

Threat values are secret values in current clients: the addon can show them but not compare or calculate with them. The color therefore comes from the threat status (0 to 3), the number and bar come from the value.

## Installation

Copy this folder as `Interface/AddOns/TrisThreat` (inside `_retail_` or `_forever_`), then run `/reload`. The game picks `TrisThreat.toc` on Retail and `TrisThreat_Camelot.toc` on Forever.

## Development

Textures are generated by `python tools/Build-Assets.py` (Pillow). Checks, from the repository root:

```
bash tools/Run-BuildHarnesses.sh                    # Lua 5.1 syntax (both TOCs) + all Fengari harnesses
node tools/Test-Core.js                             # one harness per tools/Test-*.js
pwsh tools/Test-DailyRelease.ps1 -Version <v>       # version, README, CHANGELOG, tag, repo hygiene
pwsh tools/New-ReleaseArchive.ps1 -Version <v>      # builds release/TrisThreat-<v>.zip and checks it against the TOCs
```

## Releases

A tag `v<version>` on `main` runs `.github/workflows/release.yml`: it verifies the tagged commit, builds the ZIP, uploads it to Wago and CurseForge (project IDs from the TOC fields `X-Wago-ID` / `X-Curse-Project-ID`, Retail and Forever game versions) and creates the GitHub release for WowUp. One stable release per Europe/Berlin day; a failed platform is resumed with **Actions → Release TrisThreat → Run workflow** for the same version.
