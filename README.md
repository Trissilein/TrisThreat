# TrisThreat

TrisThreat is a small World of Warcraft addon for **WoW Forever** that shows how much threat you hold on every enemy nameplate. Retail is not supported.

## Version

Current stable version: **0.1.0**.

WoW Forever compatibility (beta): interface **16001** (`TrisThreat_Camelot.toc`). Forever only: there is no Retail TOC, so Retail does not list the addon.

## What it does

- A threat element on each enemy nameplate that fights you, with the threat value (for example `70%`).
- The color grades continuously with your threat, one step per percent: green at 0 %, yellow at 50 %, red at 100 %. As a tank holding the enemy it follows your lead over the next player instead: full and green with a big lead, shrinking and turning red as they close in.
- The number is chosen automatically: threat to pull aggro (0 to 100 %) while you do not hold the enemy, your lead over the next player (above 100 %) while you hold it as a tank.
- Role detection is automatic (stance, form or aura of a tank, then the assigned group role, then your specialization role; on WoW Forever a Warrior or Paladin is a tank when a shield is equipped and no other tank is in the group, whatever aura or stance is active; the tooltip and the settings show which rule decided) and can be overridden in the settings.
- When another tank or your pet holds the enemy, the element turns blue instead of red (tank only).
- Safe target glow (damage dealers and healers): a green halo on the enemy a group tank or your pet holds while you are not on its threat list, so you know where to switch. If the tank is targeting one of them, only that one glows. Threat numbers are hidden by the game, so this is a yes/no, not a ranking; no communication between addon users is needed.
- Blizzard's own nameplate art: a second level badge (left, right, top or bottom of the health bar, or dragged anywhere), a segment in the bar's left or right end that pushes the health text aside, or a thin strip above or below the bar whose fill is your threat. There is no mode switch: drag the element in the settings preview, dots mark the spots that snap it to a badge position or turn it into the strip, anywhere else places it freely. Integrated positions can move the name, raid icon and crowd-control icons aside to make room.
- Color the number, the background, the nameplate bar, or any combination.
- The settings window shows a live copy of the Blizzard nameplate; while it is open, your target gets a test element without combat.
- Settings from `/tristhreat` (or `/tt`), the addon compartment, a Titan Panel / LibDataBroker button or the minimap icon. Right-click the minimap icon to hide it; **Show minimap icon** in the settings brings it back.

Threat values are secret values in current clients: the addon can show them but not compare or calculate with them. The color therefore comes from the threat status (0 to 3), the number and bar come from the value.

## Installation

Copy this folder as `Interface/AddOns/TrisThreat` (inside `_forever_`), then run `/reload`.

## Development

Textures are generated by `python tools/Build-Assets.py` (Pillow). Checks, from the repository root:

```
bash tools/Run-BuildHarnesses.sh                    # Lua 5.1 syntax + all Fengari harnesses
node tools/Test-Core.js                             # one harness per tools/Test-*.js
pwsh tools/Test-DailyRelease.ps1 -Version <v>       # version, README, CHANGELOG, tag, repo hygiene
pwsh tools/New-ReleaseArchive.ps1 -Version <v>      # builds release/TrisThreat-<v>.zip and checks it against the TOCs
```

## Releases

A tag `v<version>` on `main` runs `.github/workflows/release.yml`: it verifies the tagged commit, builds the ZIP, uploads it to Wago and CurseForge (project IDs from the TOC fields `X-Wago-ID` / `X-Curse-Project-ID`, Forever game version) and creates the GitHub release for WowUp. One stable release per Europe/Berlin day; a failed platform is resumed with **Actions → Release TrisThreat → Run workflow** for the same version.
